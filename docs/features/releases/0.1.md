## 已知限制与遗留项

1. **signals_log / trades_log / quality_flags 历史损失**:随原数据卷灭失,不可重建,
   空表起步(研究产物,非行情数据;行情已全量重建)。
2. **回填源为 Binance**(OKX 域名本机 DNS 污染不可达):行情语义等价,行级 provenance
   见回填报告;未来采集持续走 Binance。
3. **薄壳容器为 mock 模式**:真实推理已验证于宿主 venv(T008);容器化真实推理
   (torch 进镜像 + 权重/vendor 挂载)列为后续独立评估项。
4. **Kronos Expected Return 面板**在 mock 模式下无数据,真实模式运行后自动点亮。
5. **TimescaleDB 阶段 B(纯 Parquet 化)、宇宙扩容、评测台泛化** → F002 / M1 范围
   (spec §5 明确后移)。
6. **宿主机网络环境**:OKX 域名 DNS 污染;Binance/GitHub 直连可达;NAS sshd 流式
   传输需分块校验通道(已固化于 `backup-nas.sh`)。
