# ADR-0008：北极星改为在跑组合持续盈利，产能降级为分母与能力标定

- 日期：2026-09-15
- 状态：Accepted
- 决策人：Georg
- 背景：PRD §2.1 / §2.3 / §2.4(G2,G3) / §2.6 / FR3.5 / FR8.1 / M2；根 README「成功标准」；
  架构 §2.2「可信 Alpha」表述；ADR-0001 / ADR-0005 背景引用；F003 spec 问题陈述

## 背景

原 PRD §2.3 北极星为「滚动 28 天内新增的有效独立 `PortfolioDef` 数」——一个吞吐型指标。
即使附带质量条件（成本后为正、过最终确认、≥69 笔、复核有效、正边际），它度量的是
**部署吞吐**，不含「上线之后是否还活着」的信息：部署即衰减的策略照样计数。产能侧，
G3 与 M2 出口以「≥100 名义候选/周」为验收线；虽然 §2.1 已声明「每周候选数是工厂产能
指标，不是产品目的」，但目标表与里程碑仍把周期产出量当承诺，与产品主的意图冲突：
**要的是能持续赚钱的因子与策略，而不是一定周期内产出多少个**。

「直接用赚钱金额当北极星」也不成立：盈利不可归因（分不清 Alpha、市场 beta 与运气）、
滞后（以月兑现，等结果出现已来不及行动）、且诱发反向古德哈特（为改善数字而放松门禁
多上策略——正是 ADR-0003 与全部红线要防的事）。

## 决策

1. **北极星改为「在跑组合持续盈利」**：所有在跑组合合并资金曲线的成本后净超额收益（相对
   各策略预注册基准，不设跨策略统一收益承诺）。判据：
   - 滚动 90 天成本后净超额收益 > 0（90 天与留出窗对齐，避免 28 天被一轮市场状态切换翻转）；
   - 持续性：最近 4 个滚动 90 天窗中至少 3 个为正；
   - 约束：最大回撤 ≤ 预注册阈值；单组合可信样本量（约 ≥69 笔）；组合须有效独立、在选择期
     构建并冻结、成本后为正、通过无前视与最终确认、部署前复核有效、对现有组合正边际贡献。

   满足判据的在跑产出沿用「可信 Alpha」称谓；FR3.5 的「参与北极星计数」相应改为
   「计入北极星判据」。
2. **产能降级为分母与能力标定**：名义候选数只作漏斗转化率分母与多重检验试验计数；
   G3 / M2 的产出线改写为「单批 ≥50 候选自动评测」的批量能力标定，不设周产出配额。
   有效独立数与来源分布保留为防自欺护栏，不设数量目标。
3. **领先与分解指标体系不变**：转化效率、漏斗健康（含最大流失级指认）、线上偏差分解
   （信号质量 → 组合转换 → 成本容量 → 执行实现）照旧报告，用于定位北极星回撤的原因；
   FR7.5 周报继续报告北极星领先指标。
4. **§2.6 论题检查点保留**：它回答「长期不赚钱怎么办」（成本 pivot / 换假设源 / 书面
   止损，不允许默认续期），是新北极星的停止时钟；其分支 3 的「可信存活」从候选级口径
   改为组合级判据（≥2 个部署前复核有效的组合达标）。

## 备选方案

- 方案 A（选定）：在跑组合持续盈利北极星 + 产能降级。优点：与产品意图对齐、口径可审计
  （滚动窗/回撤/样本量全部预注册）；缺点：以月兑现，早期长期为零更可见，须靠 §2.6
  停止时钟防自我合理化。
- 方案 B：维持「28 天新增 PortfolioDef 数」。优点：与既有 G2/G7/FR3.5 文本零冲突。
  缺点：吞吐型，不含组合在跑期间的存活信息，可被「部署即衰减」满足。
- 方案 C：以绝对收益/金额为北极星。优点：最贴近「赚钱」直觉。缺点：不可归因、滞后、
  诱发放松门禁；跨市场状态不可比，无法作为可审计判据。
- 方案 D：双北极星（吞吐 + 盈利并列）。缺点：两个第一指标等于没有第一指标，吞吐数字
  会持续把注意力拉回产出量。

## 后果

- 正面：指标与「持续赚钱」的产品意图对齐；吞吐不再挤占注意力；指标职责清晰化为三层
  ——结果（北极星）、护栏（有效独立/漏斗/前视）、分母（名义计数）；量化判定全部
  预注册、可审计。
- 负面/义务：滚动窗判据需要监控面（FR6.1）与 `synthesis_report`（FR7.5）新增对应视图
  口径；早期北极星为零的时段拉长，§2.6 与正控制纪律重要性上升。
