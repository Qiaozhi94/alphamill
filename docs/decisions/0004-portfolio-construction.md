# ADR-0004：组合构建层 —— 协同池组合可部署化与 Top-K 策略映射

- 日期：2026-09-07
- 状态：Accepted
- 决策人：Georg
- 背景：AlphaGen 协同池产出需要可部署路径；PRD FR2.6 / FR4 / FR5

## 背景

AlphaGen 主引擎的核心产出是协同池（LinearAlphaPool：基础因子的线性组合，增量 IC reward
机制性防冗余）。如果部署只支持单因子策略并在多个候选中取 Top1，结果是：

1. **组合 alpha 没有部署路径**——主引擎最有价值的输出在系统里是死产出；
2. Top1-only 同时丢弃了多存活因子的组合价值：N 个存活因子 = N 个独立策略的替代方案，
   资本碎片化、费用×N、同一 pair 上多空信号冲突，均未设计。

组合构建层是因子证据转化为交易能力的必需边界，不能由 Freqtrade 策略模板临时承担。

## 决策

1. **统一可部署对象**：所有待部署策略都表示为 PortfolioDef；单因子策略是单成员组合，协同池
   meta-factor 可作为组合成员或冻结信号对象。二者走相同门禁，不因来源获得豁免。
2. **组合边际贡献门**：在选择期报告候选加入现有基准组合后的边际成本后收益、边际回撤、
   相关性与容量；没有正边际贡献的候选可进入 monitoring，但不进入待验证 PortfolioDef。
3. **因子→策略映射：Top-K 组合取代 Top1-only**：多因子通过选择期时，按成本后 Sharpe 取
   前 K 个作为同一 PortfolioDef 的候选成员（v0.1：K=3，硬上限 5），其余进 monitoring。
   K 为配置项，落 `portfolio/config.yaml`，规则
   先于数据确定。**Top-K 入选判定只允许使用选择期及更早数据**（数据边界硬约束，见
   架构文档 §4.2）。
4. **权重方案 v0.1 = 逆波动率加权**：组合内各 meta-因子按已实现波动率倒数加权。选择理由：
   参数少、无需估计协方差矩阵；等风险/最小方差等优化类权重明确后移到 v0.2+，不与 v0.1
   里程碑耦合。**逆波动率的估计窗显式限定于选择期**——不得在留出或确认窗上估计权重；若
   实现上估计窗与门禁窗分离，须在 manifest 中声明估计窗位置。
5. **换手预算为门禁输入**：每个再平衡周期设显式换手上限，v0.1 默认单周期换手 ≤100%
   （即全仓翻转一次）。换手预算作为成本模型的门禁输入，接入 ADR-0003 决策 4 的三档成本
   敏感性：超预算的候选在评测台即标记 `over_turnover_budget`，不进留出。
6. **净敞口与同 pair 冲突（v0.1 规则）**：净敞口上限 v0.1 由"每 pair 只允许一个策略持有
   活跃信号"实现；同一 pair 上出现方向冲突的候选信号时，在组合构建层先净额化（netting）
   再写信号缓存——**Freqtrade 只看到净后信号**，永不接收自相矛盾的信号流。进阶净额化
   （跨策略对冲、保证金级合并）明确后移，v0.1 不做。
7. **冻结与验证顺序**：组合构建层输入选择期存活因子，输出冻结的 PortfolioDef；随后整个
   PortfolioDef 进入 90 天留出与永久隔离最终确认。看到门禁结果后改变成员、权重、阈值或约束，
   必须生成新 ID 并从头消耗门禁预算。只有验证通过后才写净后信号缓存。

## 备选方案

- 方案 A（选定）：Top-K meta-因子 + 逆波动率权重 + 换手预算。优点：主引擎产出全有部署
  路径；实现简单、可数参数全部配置化。缺点：逆波动率在因子高相关时分散化有限，需注册表
  查重（FR2.5）与组合门兜底。
- 方案 B：维持 Top1-only。优点：零新增组件。缺点：协同池价值全丢弃，因子互补性无法验证。
- 方案 C：组合优化器（均值方差/风险平价 + 约束求解）。优点：理论上资本效率最优。缺点：
  v0.1 样本量撑不起稳健的协方差估计；复杂度先行违反冒烟闸门精神。

## 后果

- 正面：协同池产出获得完整部署路径，组合 alpha 可被门禁验证而非纸面价值；Top-K 提供
  策略间对照（champion-challenger 的雏形）；同 pair 冲突在进入 Freqtrade 前被结构化消解。
- 负面/义务：K>1 增加组合信号计算和归因复杂度；组合构建层必须在 M3 完成且通过
  独立逐 K 线重放审计（无前视三层不变）；净额化逻辑是正确性敏感代码，属检视从严范围。
- 后续行动：K / 换手预算 / 权重方案参数进 `portfolio/config.yaml`；组合构建层的验收
  标准在对应 feature spec 中定义并引用本 ADR。
